# Студия Виктории Рассохиной — studvic.ru

Статический сайт на GitHub Pages.

## Как менять цены и названия

1. Откройте `prices.xlsx`, лист **«Прайс-лист»**. Меняйте цены, названия и описания.
   - Категория и тип строки выбираются из выпадающего списка.
   - Цену можно писать как `2500`, `2 500 ₽` или текстом `от 3 500 ₽` — на сайте будет «2 500 ₽».
   - Иконки — только бесплатные из Font Awesome 6 (fontawesome.com/icons → Free).
2. Сохраните файл под тем же именем `prices.xlsx` и загрузите в репозиторий (Add file → Upload files, заменить).
3. Через 1–10 минут сайт обновится. Никакой другой файл менять не нужно.

**Проверка до публикации:** откройте сайт с `?admin=1` (например `https://studvic.ru/?admin=1`) или нажмите Shift+Alt+A,
загрузите файл — сайт покажет предпросмотр и список ошибок (неизвестная категория, пустая цена и т. п.).
Предпросмотр виден только вам; посетителям ничего не меняется, пока файл не заменён в репозитории.

`prices.json` — запасной вариант, если Excel не прочитался. Основной источник — `prices.xlsx`.

## Структура

- `index.html` — разметка
- `css/style.css` — стили и дизайн-токены (`:root`)
- `js/app.js` — прайс из Excel, вкладки, меню, галерея
- `fonts/` — шрифты Inter и Cormorant Garamond (хранятся на сайте)
- `*.jpg` — фото (настоящие JPEG, ≤ 250 КБ). Новые фото с iPhone нужно сохранять как JPEG, а не HEIC.
